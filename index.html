Como jogar
  • Clique numa pista ou numa casa e digite: o cursor anda sozinho.
  • Use as setas para andar e o Backspace para apagar.
  • Clique de novo num cruzamento para trocar entre horizontal e vertical.
  • Clique em Conferir para ver o que está certo.
